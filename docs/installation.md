# Zambia Payments App - Installation Guide

## Prerequisites

- Frappe Framework installed
- ERPNext installed
- Python 3.7+
- Node.js 14+

## Installation Steps

### 1. Install the App

```bash
# Navigate to your bench directory
cd /path/to/your/bench

# Create new app
bench new-app zoyktech_zambia_payments

# Install on your site
bench --site your-site-name install-app zoyktech_zambia_payments
